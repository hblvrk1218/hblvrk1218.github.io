Developed a modular **ROS2-based autonomous driving architecture** for dynamic obstacle avoidance, lane changing, and overtaking using camera and LiDAR sensors.

The system separates perception, decision-making, and control into independent ROS2 nodes and integrates them through node-level communication for autonomous driving in dynamic traffic scenarios.

## Key features

- **Modular ROS2 architecture** separating perception, decision, and control
- **YOLOv8-based perception** for lane and vehicle recognition
- **LiDAR-based obstacle detection** for surrounding environment awareness
- **Pure Pursuit algorithm** for path tracking and steering control
- **Finite State Machine (FSM)** for lane-change and overtaking decisions
- Dynamic obstacle avoidance and overtaking in a multi-vehicle environment
