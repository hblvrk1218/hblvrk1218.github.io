Developed an AI-assisted driver monitoring and braking evaluation system designed to detect drowsy driving and provide appropriate braking warnings.

The system analyzes driver behavior using camera-based facial information and estimates the distance to a preceding vehicle using the **MiDaS Small depth estimation model**.

## Key features

- **Camera-based driver monitoring** for detecting drowsiness
- Analysis of **eye blinking and yawning patterns**
- Driver alert mechanism when drowsiness is detected
- **MiDaS Small-based depth estimation** using a forward-facing camera
- Braking timing evaluation based on estimated vehicle distance and driving conditions
- Integrated driver monitoring and driving-safety assistance system
